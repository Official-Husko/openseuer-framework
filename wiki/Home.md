**ObenseuerExtended** is a set of mods for [Obenseuer](https://store.steampowered.com/app/951240/Obenseuer/): fixes for bugs in the game, performance fixes, optional tweaks, a cheat menu, compressed saves and, one day, co-op. It brings its own mod loader, so you don't need BepInEx, and everything shows up in a MODS menu inside the game.

It's early: there are only pre-releases so far. Back up your saves before you try it.

## Start here

- **[Installing](Installing)**: download, install, update and remove it again.
- **[The MODS menu](The-MODS-Menu)**: where every mod, setting and hotkey lives.
- **[Reporting bugs](Reporting-Bugs)**: one button makes a report with everything we need.
- **[Troubleshooting](Troubleshooting)**: a black window at start, mods missing, after a game update.

## The mods

| Mod | What it does |
| --- | --- |
| [Unofficial ObenPatches](Unofficial-ObenPatches) | Fixes for bugs in the game itself, each with its own switch. |
| [Performance Fixes](Performance-Fixes) | Stops the game from repeating work every frame that it doesn't need to. |
| [Game Tweaks](Game-Tweaks) | Optional changes to needs, stacks, crafting, renovations, day length, and a third-person camera. |
| [Cheat Menu](Cheat-Menu) | Cheats on Insert, and a developer menu for stuck quests. |
| [ObenSave](ObenSave) | Compressed saves, off until you turn it on. |
| [ObenCoop](ObenCoop) | Co-op, still being built. |

The framework and the UI kit are mods too; the others need them.
